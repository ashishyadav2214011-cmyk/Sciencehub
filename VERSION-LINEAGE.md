# V1–V95 Version Lineage

This file maps every version number into the integrated archive. It intentionally distinguishes preserved historical source from lineage-only records.

- V1–V73: lineage records; original per-version executable source is not fully present in the current repository snapshot.
- V74–V95: cumulative integration lineage, with the current V95 integration layer preserved in the package.
- V95: current master integration layer.

The archive is therefore **integrated and honest**: it connects the version history without inventing missing historical code.
