# ScienceHub V80 — UPMSP 2026–27 Syllabus + PYQ Integration

ScienceHub now contains a structured syllabus index for the user's five core subjects in **Class 11 and Class 12** for **UPMSP academic session 2026–27**:

- Hindi — 101
- English — 117
- Physics — 151
- Chemistry — 152
- Biology — 153

## What is integrated

- Official UPMSP unit/section headings and marks where available in the official PDFs.
- Topic-level study labels under each syllabus section.
- Class 11 / Class 12 switch.
- Official syllabus PDF links.
- PYQ Hub 2020–2026 links.
- A non-fabrication rule: ScienceHub does not invent a previous-year question when the original paper has not been verified.
- Local JSON files so the syllabus index can work offline after the first cache/install.

## Important accuracy note

The official UPMSP syllabus PDFs explicitly identify the session as **2026–27**. The structured data in `data/upmsp_syllabus_2026_27.json` is derived from those official syllabus documents. PYQ year slots are source slots, not fabricated question records; a paper should be attached to a topic only after verification.
