# V93 Integration Definition

This build is the approved integration target from the current ScienceHub refinement discussion.

### A — Existing foundation retained
Home cockpit, UPMSP data, PWA/offline foundation, AI role UI, Sukoon.Brain chat/icon/settings.

### B — Functional integration
The common study data model links syllabus topics with study activity, practice, mistakes, revision, progress and time records. Home reads those systems for mission/next-action/intelligence summaries.

### C — Home refinement
The Home screen is treated as a private futuristic study cockpit, removes user-facing development step labels, keeps the ScienceHub visual identity, and exposes the connected Study OS + Sukoon.Brain without turning the Home page into a warehouse.

### Explicit limitations
- PYQ registry is not a complete verified 2020–2026 question bank.
- PCB opportunities/exam tracker are structural unless fresh verified data is supplied.
- Sukoon local mode is deterministic/local; generative AI requires a configured endpoint.
- GitHub Pages deployment is not part of ZIP creation.
